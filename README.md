# Python Practice Assignment

Solutions for basic Python practice problems focusing on user input, arithmetic operations, and conditional grading logic[cite: 1, 2].

## Repository Structure

```text
python-practice-assignment/
├── personal_calculator.py
├── grade_calculator.py
└── README.md
```[cite: 3]

## Tasks Overview

### 1. Personal Calculator (`personal_calculator.py`)
* Takes user's name, age, and two numbers[cite: 1].
* Calculates and displays addition, subtraction, multiplication, and division using f-strings[cite: 1].

### 2. Student Grade Calculator (`grade_calculator.py`)
* Takes student name and marks for 3 subjects (Math, English, Python)[cite: 1, 2].
* Validates marks (0–100)[cite: 2].
* Calculates average and assigns letter grade (`A+`, `A`, `A-`, `B`, `C`, `F`)[cite: 1, 2].

## How to Run

```bash
python personal_calculator.py
python grade_calculator.py
